# 示例工作流（0.15.1）

更新插件、重启ComfyUI并刷新页面后导入JSON。推荐从简洁模式开始，填写自己的CanvasPro API Key（https://api.canvasproai.com/keys）。

| 示例 | 用途 |
| --- | --- |
| [简洁文生图](简洁文生图-Simple-Text-to-Image.json) | 简洁生图→保存图片 |
| [简洁多图编辑](简洁多图编辑-Simple-Multi-Image-Edit.json) | 两张加载图像→简洁生图→保存图片；先选择自己的图片 |
| [简洁多张并发](简洁多张并发-Simple-Multi-Image-Batch.json) | 同一条完整提示词生成3张，count可改1–8，每张独立计费 |
| [多任务并发](多任务并发-Multi-Task-Batch.json) | 多个不同提示词任务→批量执行 |
| [混合模型并发](混合模型并发-Mixed-Model-Batch.json) | 不同模型和参数一起执行 |
| [多图编辑](多图编辑-Multi-Image-Edit.json) | 原独立任务与批量执行模式 |
| [结果恢复](结果恢复-Result-Recovery.json) | 单独打开，粘贴原report或tasks_json，不重新生图 |

CanvasPro简洁模式：填写自己的CanvasPro API Key（https://api.canvasproai.com/keys）。不接参考图为文生图，接入图片为编辑/融合；所有换行属于同一条完整提示词。
count为出图张数，1–8张，每张是独立收费请求。高级设置可改concurrency、质量和等待时间。
模型参数自动适配：GPT使用宽高或auto，香蕉/即梦使用比例与清晰度；不支持的控件隐藏。即梦本地图自动上传共用ImgBB，3小时后删除，用户无需图床Key。
seed是批次标识，不是上游图像种子。randomize可再次生成；fixed且所有输入相同恢复已有结果。改变提示词、模型、参考图、count或seed会创建新收费任务。
report显示执行阶段、错误、资源网址和缓存信息。下载失败时另开“结果恢复”示例，粘贴原report重试，不要同时运行原随机种子生成流程。资源网址可能有有效期，分享日志前请删除网址。

optimized-api.json是原批量模式API格式，不能作为界面工作流拖入。


## 异步分步提交与累计队列（0.15.0）

[异步分步工作流](异步分步工作流-Async-Two-Step.json)

异步分两步：
1. 提交节点与批量查询节点填写同一queue_key（默认queue-001），两个节点都填写自己的CanvasPro API Key。
2. 保持提交节点启用，连续运行一次、两次、三次；seed的生成后控制设randomize，每次提交加入新任务。fixed且输入相同不会重复收费，也不会重复加入队列。
3. 提交结束后，将“异步提交”节点设为禁用/从不（mode 2），再运行工作流；批量查询会获取同队列历次提交的全部任务并下载。
同一队列的提交节点仍启用时，查询节点自动跳过，保存图片也会跳过，不会在提交阶段等待生成。
查询可反复运行，尚未完成或下载失败时继续查询；成功图片优先读取缓存，原网址过期可勾选refresh_urls续查原任务。
队列保存在本机user/canvaspro，重启后仍保留。要开始另一批任务使用新的队列名；查询不清空旧队列。
异步提交仅列出能返回任务号的型号；W/SR/FULL同步型号仍使用简洁生图。参考图自动处理，需图床时使用内置ImgBB，3小时后删除。
不需要复制、合并多个task_id。report含批次、原任务号及资源网址，分享日志前删除临时网址。


## 查询界面说明（0.15.1）

队列查询界面（0.15.1）：默认隐藏model，queue_key会查询该队列的全部模型，不按下拉框筛选。tasks_json标为“单独任务（可选，留空查询整个队列）”；留空或完整JSON/批次编号时隐藏型号，仅手工填写平台任务号时显示“手动任务号对应模型”。字段只隐藏，旧工作流序列化位置和后端兼容性保留。
