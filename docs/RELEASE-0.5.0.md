# 0.5.0

新增批量执行节点：直接接收自动增加的任务入口，整批预校验，再并发提交、查询、下载。每个任务保存独立模型，支持混合模型批次及进程重启后的查询。SQLite 增量添加任务 model 列，旧数据回退到批次 model，不改变旧任务记录和提交指纹。

独立任务图片入口自动增加至模型上限；质量、URL 和执行等待/超时参数移入高级开关。新增简化及三模型示例。旧节点保持兼容。

使用本地模拟 HTTP、真实 SQLite、PNG/torch 测试；不使用生产凭据，不发送付费请求。

验证：21 项 Python 集成测试、10 项前端逻辑测试通过。真实 ComfyUI 加载 11 个节点、校验全部 API 示例，执行两个不同模型任务并通过 SaveImage 保存不同尺寸图片。工作流全部连线与类型检查通过。未启动实际 ComfyUI 服务或进行本次视觉检查。
